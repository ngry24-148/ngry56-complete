コンプリート賞 特設サイト（公開用）

■ 置き方
  index.html と files/ フォルダをサーバーに置いてください（https 推奨）。

■ 受賞者の入り方
  全員共通のURLを開く → カードに書いた8文字のアクセスコード（XXXX-XXXX）を入力。
  ハイフン・空白・大文字小文字・全角半角は気にせず入力できます。
  コードに 1 と I は使っていないので、打ち間違えても L として扱います。
  一度開いた端末は、次回からコード入力なしで開けます。

■ 特典ファイル
  files/ に次の名前で置くとダウンロードボタンにつながります。
    wallpaper-phone.png / wallpaper-pc.png / certificate.pdf
  サムネイル画像は index.html の「[プレビュー画像]」部分を <img> に差し替えてください。

■ 仕組み
  ページ内にはコード本体ではなく SHA-256 ハッシュ1000件だけを入れています。
  ソースを見てもコードは分かりません。
  ただし files/ の特典ファイル自体は、そのURLを知っていれば誰でも取得できます。
